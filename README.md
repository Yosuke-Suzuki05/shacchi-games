# 🎮 AIでゲームを1から作る方法

> **AIゲーム開発 勉強会フォローアップ資料**
> 「喋るだけで、ゲームが作れる時代へ。」── 当日やった流れを、おうちで再現できるようにまとめました。
> プログラミング未経験でもOK。コードは1行も書きません。**日本語でお願いするだけ**です。

---

## ✅ この通りにやると、こうなります

当日の実演で作ったのと同じ、**スマホで遊べる単一HTMLのゲーム**が作れます。

- 完成例（遊べます）👉 **https://yosuke-suzuki05.github.io/shacchi-games/**
- 仕組み：1つの `.html` ファイルだけ。ダウンロードしてダブルクリックでも動くし、GitHubに上げればURLで世界中に共有できます。

---

## 🧰 STEP 0｜準備するもの（最初の1回だけ）

| 必要なもの | 何のため | 入手先 |
|-----------|---------|--------|
| **Claude Code**（または Codex） | AIに日本語で指示してゲームを作ってもらう本体 | https://claude.com/claude-code |
| **GitHub アカウント** | 完成したゲームをネットに公開する（無料） | https://github.com/signup |

### Claude Code のインストール（ざっくり）
1. 公式ページの手順に従ってインストール（Mac / Windows どちらもOK）
2. ターミナル（黒い画面）で `claude` と打つと起動します
3. 作業用のフォルダを1つ作って、その中で `claude` を起動するのがおすすめ

> 💡 ターミナルが怖い人へ：最初だけ少し慣れが要りますが、起動してしまえば、あとは**ぜんぶ日本語の会話**です。身構えなくて大丈夫。

---

## 🗺 全体の流れ（たった4ステップ）

```
① お題を決める  →  ② ゲームの土台を作る  →  ③ キャラ・デザインを入れる  →  ④ 完成！GitHubで公開
```

ポイントは **「一気に全部頼まない」**。まず動くものを出して、少しずつ育てていきます。

---

## 🎯 STEP 1｜お題を決める

「どんなゲームにするか」を一言で決めます。むずかしく考えず、**自分の"あるある"**でOK。

- 例：「定時で帰りたいのに上司に捕まる」→ 逃げるゲーム
- 例：「退職届を出して逃げ切る」→ ランニングゲーム
- 例：「もぐらたたき」「すいか割り」みたいな超シンプルなものでも全然アリ

> 当日の実演では「**会社から逃げ切るランニングゲーム**（主人公：たま子）」を作りました。この資料もそれを例に進めます。

---

## 🏗 STEP 2｜ゲームの土台を作る

Claude Code に、まずは**「とりあえず動くもの」**をお願いします。下のプロンプトをコピペしてみてください。

### 🟦 プロンプト①（最初の一撃）
```
スマホで遊べるシンプルなゲームを、HTML1ファイルだけで作ってください。
内容は「会社から逃げ切るランニングゲーム」。
主人公が画面を右に向かって自動で走っていて、画面をタップするとジャンプ、
もう一度タップで二段ジャンプします。
ドット絵風で、夕暮れの空・遠くにビル群の背景にしてください。
タイトル画面に「逃げる！」ボタンを置いて、まずは走ってジャンプできるところまで動かしてください。
```

これで「タイトル → 走ってジャンプできる画面」が出てきます。**ここで最初の「おおっ」が来ます。**

### 🟦 プロンプト②（手応えを足す）
```
いい感じです！次に、右から障害物が流れてくるようにして、
ジャンプで飛び越えるゲームにしてください。
ぶつかったらゲームオーバーで「残業確定…」と表示してください。
障害物は、ちゃんとジャンプで避けられる間隔にしてください。
```

これで「避けゲー」が成立します。**もうゲームです。**

### 🟦 プロンプト③（スコアとゴール）
```
走った距離をスコアにして、画面上に表示してください。
ハイスコアも記録してください。
ゲームオーバー画面に「もう一回」ボタンと、結果をX（旧Twitter）でシェアするボタンを付けてください。
```

> 💡 **動きを見る方法**：Claude Code が作った `.html` ファイルをダブルクリックすればブラウザで開けます。スマホで見たいときは STEP 4 で公開してから。

---

## 🎨 STEP 3｜キャラクター・デザインを入れる

ここで一気に「自分の作品」になります。**好きな画像を主人公にできます。**

### 画像を使う場合
1. 主人公にしたい画像（透過PNGがおすすめ）を、ゲームの `.html` と**同じフォルダ**に入れる
2. Claude Code にこうお願いする：
```
このフォルダにある character.png を主人公として使ってください。
背景の上で、走っているように表示してください。
```

### 絵がない場合
```
主人公をドット絵（ピクセルアート）でかわいく描いてください。
色は◯◯で、△△な雰囲気にしてください。
```
コードだけでキャラを描いてもらうこともできます。

### 色・世界観を直す
```
全体の色をもっとポップなピンク系にしてください。
タイトルの文字を大きく、目立つようにしてください。
```
> **遠慮なく何度でも直してOK。** 「もう少し○○して」が魔法の言葉です。

---

## 🚀 STEP 4｜完成！GitHubで公開する

作ったゲームを、世界中の人が遊べるURLにします。**Claude Code にお願いすれば、ほぼ全部やってくれます。**

```
このゲームをGitHubに公開したいです。
GitHub Pagesで、誰でもURLで遊べるようにする手順を教えながら、一緒にやってください。
```

ざっくりの流れ（Claude Codeが手伝ってくれます）：
1. GitHubで新しいリポジトリを作る（Public）
2. ゲームのファイルをアップロード（`git` というコマンドを使います／Claude Codeが案内）
3. リポジトリの設定（Settings → Pages）で公開をON
4. 数十秒待つと `https://（あなたのID）.github.io/（リポジトリ名）/` で遊べる！

> 🎉 このURLをスマホで開けば、自分の作ったゲームがその場で遊べます。友達にもシェアできます。

---

## 🌟 うまく作る「3つのコツ」（当日のタネ明かし）

1. **一気に全部頼まない** ── まず動くものを出して、少しずつ育てる
2. **完成形を具体的に伝える** ── 色・世界観・キャラのセリフまで言葉にする
3. **遠慮なく直す** ── 「もう少し○○して」で何度でも調整できる

この"指示の出し方"が上手くなると、ゲーム以外（資料作り・アプリ・自動化）にも全部応用できます。

---

## 🆘 つまずいたら

| こんなとき | こうする |
|-----------|---------|
| AIの出力がエラーになる | 「もう一度お願いします」「さっきのエラーを直してください」 |
| 画面が崩れた | 「さっきの状態に戻して、○○だけ直してください」 |
| 難しすぎ／簡単すぎ | 「障害物の間隔を広げて（狭めて）ください」 |
| 画像が表示されない | 画像ファイルが `.html` と同じフォルダにあるか確認 |
| そもそも動かない | ファイルをダブルクリックでブラウザが開くか確認。スマホは公開後にURLで |
